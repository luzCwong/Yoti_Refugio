# Frontend — Yoti Refugio MVP

## Estructura de componentes
```
src/components/
├── chat/          → Chat con Yoti Escucha (mensajes, input, botones rápidos)
├── emergency/     → Modo Emergencia (botón 112, mensaje preparado, ubicación)
├── camouflage/    → Pantalla camuflada "Mis recetas" y salida rápida
└── resources/     → Sección de recursos y ayuda (016, centros, guías)
```

## Páginas planificadas
| Página | Ruta | Descripción |
|--------|------|-------------|
| Camuflada | /recetas | Entrada discreta tipo app de recetas |
| Principal | /mvp | Activación de Yoti y chat principal |
| Emergencia | /emergencia | Botón 112, mensaje preparado, salida rápida |
| Recursos | /recursos | 016, centros de igualdad, guías |
| Neutra | /notas | Pantalla de escape (inocua) |
| Demo institucional | /maule | Explicación del MVP para evaluadores |
